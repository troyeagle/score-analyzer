## 一、当前渲染规则

### 1.1 小节音符数量决定因素

每个小节显示的音符数量由以下因素决定：

1. **拍号**: 决定每小节的总时值
   - 4/4 拍 = 4 拍
   - 3/4 拍 = 3 拍

2. **音符类型**: 决定每个音符的时值
   - whole (全音符) = 4 拍
   - half (二分音符) = 2 拍
   - quarter (四分音符) = 1 拍
   - eighth (八分音符) = 0.5 拍
   - 16th (十六分音符) = 0.25 拍

3. **附点**: 增加原时值的一半
   - 附点四分音符 = 1.5 拍

## 二、重复渲染问题分析

### 2.1 问题现象

某些小节的音符被重复渲染，导致：
- 同一个音符显示多次
- 音符重叠

### 2.2 可能原因

1. **Voice 重复**:
   ```typescript
   // 如果 measure.voices 中有重复的 voice
   measure.voices.forEach((voice, voiceId) => {
     // 同一个 voice 被处理多次
   })
   ```

2. **音符重复**:
   ```typescript
   // 如果 voice.notes 中有重复的音符
   voice.notes.forEach(note => {
     // 同一个音符被添加多次
   })
   ```

3. **渲染循环问题**:
   ```typescript
   // allVoices 可能包含重复项
   allVoices.forEach(({ voice, staveIndex }) => {
     voice.draw(context, staves[staveIndex])
   })
   ```

### 2.3 调试方法

在 `renderSingleStaffLine` 中添加日志：

```typescript
console.log(`小节 ${measure.number}:`)
console.log(`  voices 数量: ${measure.voices.size}`)
console.log(`  allVoices 数量: ${allVoices.length}`)

measure.voices.forEach((voice, voiceId) => {
  console.log(`  voice ${voiceId}: ${voice.notes.length} 个音符`)
})
```

## 三、正确渲染规则

### 3.1 每个小节应该显示多少音符

**规则**: 每个小节显示该小节内所有 voice 的所有音符，不重复

```typescript
// 正确的做法
const uniqueVoices = new Map<number, Voice>()

measure.voices.forEach((voice, voiceId) => {
  if (!uniqueVoices.has(voiceId)) {
    uniqueVoices.set(voiceId, voice)
  }
})

uniqueVoices.forEach((voice) => {
  // 渲染这个 voice 的音符
})
```

### 3.2 音符时值与拍号的关系

以 4/4 拍为例：
- 每小节 4 拍
- 所有音符的总时值应该等于 4 拍
- 如果不等于 4 拍，可能是：
  - 有休止符
  - 有连音线
  - 数据错误

### 3.3 Solo 小节 1 的正确渲染

```
小节 1:
- 拍号: 4/4
- 音符: 8 个八分音符
- 音高: G#4 G#4 G#4 G#4 G#4 G#4 G#4 G#4
- 总时值: 8 × 0.5 = 4 拍 ✓
```

## 四、修复方案

### 4.1 防止 Voice 重复

```typescript
// 在 renderSingleStaffLine 中
const processedVoices = new Set<string>()

measure.voices.forEach((voice, voiceId) => {
  const voiceKey = `${measure.number}-${voiceId}`
  if (processedVoices.has(voiceKey)) {
    console.warn(`跳过重复的 voice: ${voiceKey}`)
    return
  }
  processedVoices.add(voiceKey)
  
  // 处理这个 voice
})
```

### 4.2 防止音符重复

```typescript
// 在 createVexFlowNotes 中
const processedNotes = new Set<string>()

notes.forEach(note => {
  const noteKey = `${note.pitch}-${note.type}-${note.duration}`
  if (processedNotes.has(noteKey)) {
    console.warn(`跳过重复的音符: ${noteKey}`)
    return
  }
  processedNotes.add(noteKey)
  
  // 创建 VexFlow 音符
})
```
