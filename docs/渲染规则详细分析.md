## 一、当前渲染规则

### 1.1 布局参数

```typescript
measuresPerLine = 4  // 每行显示4个小节
measureWidth = availableWidth / measuresPerLine  // 每个小节的宽度
```

### 1.2 渲染流程

```
1. 计算最大小节数 maxMeasures
2. 计算总行数 totalLines = ceil(maxMeasures / measuresPerLine)
3. 按行渲染：
   - 行 0: 小节 0-3 (lineStart=0, lineEnd=4)
   - 行 1: 小节 4-7 (lineStart=4, lineEnd=8)
   - 行 2: 小节 8-11 (lineStart=8, lineEnd=12)
   ...
```

### 1.3 关键代码

```typescript
for (let line = pageStartLine; line < pageEndLine; line++) {
  const lineStart = line * measuresPerLine  // 数组索引，从0开始
  const lineEnd = Math.min(lineStart + measuresPerLine, maxMeasures)
  
  for (let partIndex = 0; partIndex < parts.length; partIndex++) {
    const part = parts[partIndex]
    // 渲染该声部的这一行小节
    renderSingleStaffLine(context, part, lineStart, lineEnd, ...)
  }
}
```

## 二、Solo 声部 (1-10小节) 分析

### 2.1 Solo 声部结构

- **声部ID**: P1
- **声部名称**: Solo
- **谱表数**: 1 (单谱表)
- **Voice数**: 1 (单声部)

### 2.2 小节数据示例

| 小节号 | 音符数 | 音符序列 |
|--------|--------|----------|
| 1 | 8 | G#4 G#4 G#4 G#4 G#4 G#4 G#4 G#4 |
| 2 | 6 | G#4 G#4 G#4 G#4 G#4 C#5 |
| 3 | 6 | F#4 F#4 F#4 F#4 F#4 F#4 |
| 4 | 5 | F#4 F#4 F#4 F#4 B4 |
| 5 | 8 | E4 E4 E4 E4 E4 C#4 E4 F#4 |
| 6 | 7 | G#4 G#4 G#4 F#4 G#4 F#4 E4 |
| 7 | 5 | B4 G#4 F#4 E4 C#4 |
| 8 | 6 | B4 G#4 C#5 B4 G#4 F#4 |
| 9 | 2 | F#4 E4 (附点二分) |
| 10 | 1 | E5 (全休止 + 四分) |

### 2.3 渲染流程

```
行 0 (lineStart=0, lineEnd=4):
  - 渲染小节索引 0-3 (即小节号 1-4)
  - 每个小节独立五线谱

行 1 (lineStart=4, lineEnd=8):
  - 渲染小节索引 4-7 (即小节号 5-8)
  - 每个小节独立五线谱

行 2 (lineStart=8, lineEnd=10):
  - 渲染小节索引 8-9 (即小节号 9-10)
  - 每个小节独立五线谱
```

## 三、Piano 声部 (1-10小节) 分析

### 3.1 Piano 声部结构

- **声部ID**: P7
- **声部名称**: Piano
- **谱表数**: 2 (大谱表：高音+低音)
- **Voice数**: 1-2 (可能有多个voice)

### 3.2 特殊处理

Piano 使用 `renderGrandStaffLine` 方法：
1. 为每个小节创建两个五线谱（高音+低音）
2. 使用花括号连接
3. 根据 voice.staff 分配音符到对应谱表

### 3.3 Voice 分配规则

```typescript
if (voice.staff === 2) {
  bassVoices.push({ voice: vexVoice, staveIndex })
} else {
  trebleVoices.push({ voice: vexVoice, staveIndex })
}
```

## 四、重复渲染问题分析

### 4.1 可能原因

1. **数组索引问题**：
   - `part.measures[i]` 中的 `i` 是从 0 开始的数组索引
   - 如果小节编号不是连续的，可能导致索引错位

2. **Voice 重复**：
   - 如果同一个音符被添加到多个 voice 中
   - 或者 voice 的 notes 数组包含重复数据

3. **渲染循环问题**：
   - `allVoices.forEach` 可能对同一个五线谱渲染多次

### 4.2 调试建议

在 `renderSingleStaffLine` 中添加日志：

```typescript
console.log(`小节 ${measure.number}: staveIndex=${staves.length - 1}, voices=${allVoices.length}`)
```

## 五、正确渲染规则

### 5.1 每个小节显示多少音符

**规则**: 每个小节显示该小节内所有 voice 的所有音符

```typescript
// 对于每个小节
measure.voices.forEach((voice) => {
  // 该 voice 的所有音符
  voice.notes.forEach(note => {
    // 渲染这个音符
  })
})
```

### 5.2 音符时值与拍号的关系

以 4/4 拍为例：
- 每小节 4 拍
- 四分音符 = 1 拍
- 八分音符 = 0.5 拍
- 一个小节最多 8 个八分音符

### 5.3 实际示例

**Solo 小节 1**:
- 拍号: 4/4
- 音符: 8 个八分音符
- 时值: 8 × 0.5 = 4 拍 ✓

**Solo 小节 2**:
- 拍号: 4/4
- 音符: 4 个八分 + 1 个四分
- 时值: 4 × 0.5 + 1 × 1 = 3 拍 (不完整小节，使用 setStrict(false))

## 六、修复方案

### 6.1 确保索引正确

```typescript
// 使用 measure.number 而不是数组索引
const measureIndex = i - lineStart  // 行内索引
const staveIndex = measureIndex      // 对应的五线谱索引
```

### 6.2 避免重复渲染

```typescript
// 确保每个 voice 只渲染一次
const renderedVoices = new Set()
allVoices.forEach(({ voice, staveIndex }) => {
  const key = `${staveIndex}-${voice.tickables.length}`
  if (!renderedVoices.has(key)) {
    renderedVoices.add(key)
    voice.draw(context, staves[staveIndex])
  }
})
```
